# Operator runbook

Install and migrate explicitly with `DATABASE_URL=... ./scripts/migrate.sh`. Startup performs only a read-only database connection check, starts owned child processes, and refuses occupied ports. Set a strong JWT secret; experimental and provider-backed routes remain off by default.

Dispatch is blocked by stale telemetry, missing safety evidence, absent independent operator approval, constraint violations, or missing provider receipts. GPS/SCADA/ERP/weather/device/drone connections require credentials, signed contract fixtures, sequence replay tests, and a manual fallback drill. Never treat AI output as autonomous equipment authority; site safety personnel own final dispatch.
